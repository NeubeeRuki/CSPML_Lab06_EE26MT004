How It Works

1. Chat

Each chat is saved in SQLite. Questions and answers append continuously like a messenger conversation.

2. Context

Select NCERT folders or Library files/folders from the right panel. The selected context is stored with the conversation.

3. RAG

The V3 TF-IDF pipeline retrieves relevant indexed chunks from the selected knowledge folder.

4. Qwen

The retrieved context and conversation history are sent to Qwen3-4B-Instruct-2507 through Hugging Face.

5. Library

Upload and organize your own PDFs/TXT/MD files. Library folders can be used as chat context.

6. Settings & Analytics

Saved response preferences and application-level usage statistics are available locally.

7. Deployment

FastAPI serves the GUI and API from one application and remains compatible with Render deployment.
